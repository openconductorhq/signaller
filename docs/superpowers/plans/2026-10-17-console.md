# signaller console Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A live "cockpit" page at `http://127.0.0.1:8787/ui` to watch and change the router's routing: lever override, ordered rules (incl. a user rule language and a small-model prompt classifier), request feed with explanations, and per-turn doubling with side-by-side comparison.

**Architecture:** The existing stdlib router grows a routing engine (rule language + immutable config swapped atomically), a classifier client, a doubler (background shadow requests), a SQLite stats store with one writer thread, and a `/ui` handler serving a no-build static page plus a JSON API. Request threads never wait on stats or shadows.

**Tech Stack:** Python 3.12 standard library only (`http.server`, `http.client`, `sqlite3`, `threading`, `json`, `re`), plain HTML/CSS/JS, vendored woff2 fonts. Tests: `unittest` run with `python3 -m pytest`.

**Spec:** `docs/superpowers/specs/2026-10-17-console-design.md` (builds on `docs/superpowers/specs/2026-10-16-signaller-design.md`). Mockups: `docs/superpowers/specs/2026-10-17-console/cockpit-v2.html`, `rule-editor.html`.

## Global Constraints

- Python 3.12 stdlib only; no pip dependencies, no npm, no build step, no frontend framework.
- Listen on loopback only (unchanged). Page loads nothing from the internet: fonts are files in `ui/fonts/`.
- Router adds < 5 ms median per request (classifier excluded); request threads never block on SQLite, the classifier beyond its time limit, or shadows.
- No silent rerouting: a failed chosen track fails the request; never fall back to the other track.
- A shadow answer never reaches Claude Code; the served response is byte-identical with or without doubling.
- Never write headers, credentials or full request bodies to disk; stderr log never contains prompt text.
- Files under `~/.config/signaller/` are created mode 0600: `console.json`, `stats.db`.
- Only `POST /v1/messages` appears in Departures/stats/pairs; `count_tokens`, passthrough and forbidden requests are only logged to stderr.
- Classifier never calls on `tier == opus`; doubling default rate is 0.
- Copy on the page follows the spec's wording (lever labels "Anthropic / Rules / Local" with "everything, ignore rules" / "follow the rulebook"; "Otherwise → …"; "Which did better on this turn? Local / Anthropic / About the same"; "Forget all pairs").
- All 30 existing tests keep passing (route tests are ported in Task 2, not deleted).

## Review Focus

1. Classifier slow or LiteLLM down while a turn is running: every request of the turn must still route within the time limit plus a few ms, and only one classifier call per turn may be in flight (Task 3 test `test_concurrent_same_text_one_call`).
2. A doubled turn where the local shadow takes minutes and Anthropic steps keep coming: steps must be skipped as "busy", not queued, and the served stream must not slow (Task 6 test `test_busy_local_shadow_skips_not_queues`).
3. Corrupt or hand-edited `console.json` at startup: router must start on defaults, move the file to `console.json.bad`, and show a banner (Task 4 test `test_corrupt_config_falls_back`).
4. A rule referencing `label` on an opus request: must not call the classifier, `label` is `none` (Task 2 test `test_label_on_opus_never_classifies`).
5. Browser page open on another localhost port (e.g. a dev server on :3000) posting to `/ui/api/config`: must be 403 (Task 7 test `test_other_localhost_port_origin_forbidden`).

### Task 1: Rule language

**Files:**
- Create: `rulelang.py`
- Test: `tests/test_rulelang.py`

**Interfaces:**
- Produces:
  - `class RuleError(ValueError)` with attributes `message: str`, `line: int` (1-based), `col: int` (1-based); `str()` = `"line L, col C: message"`.
  - `FIELDS: dict[str, str]` — field name → type, exactly `{"text": "text", "tag": "tags", "tier": "word", "model": "text", "tokens": "number", "subagent": "bool", "label": "word"}`. Adding a field later = one entry here plus one line in `routing.Features.get`.
  - `@dataclass(frozen=True) class Line: cond: object; track: str` (track `"anthropic"|"local"`).
  - `parse(src: str) -> list[Line]` — one or more lines `when <cond> go anthropic|local`, separated by newlines; blank lines ignored. Raises `RuleError`.
  - `evaluate(cond, get: Callable[[str], object]) -> bool` — `get(field)` returns the field value (lazy; `label` may trigger a classifier call, so `get` is called only for fields the condition actually reaches, left to right, short-circuit).
  - `fields_used(lines: list[Line]) -> set[str]`.

Grammar (spec "The rule language"): `not` binds tightest, then `and`, then `or`; parentheses. Comparisons: `field is value`, `field contains value`, `field matches /re/flags` (flags subset of `ims`), `field > < >= <= number` (number with optional `k` = ×1000). Values: `"double quoted"` (backslash escapes `\"` and `\\`) or a bare word `[A-Za-z0-9_.-]+`. Bare `subagent` alone is a condition (true when yes); `subagent is yes|no` also allowed. Keywords are case-insensitive. Semantics: `is` case-insensitive equality; on `tag` (a set of lowercase words) means "has this tag" (value lowercased, leading `#` stripped); `contains` case-insensitive substring (text/model only); `matches` uses `re.search` with compiled flags (compile at parse; bad regex → `RuleError`); numeric ops only on `number` fields. Type mismatches (e.g. `tokens contains x`, `text > 5`, unknown field) are `RuleError` at parse.

Round-trip equal.
  - `@dataclass class Decision: track: str; reason: str; explanation: list[dict]` — each explanation item `{"rule": name, "outcome": str, "decided": bool}`.
  - `route(cfg: RoutingConfig, f: Features, classify: Callable[[Features, ClassifierSettings], ClassResult]) -> Decision`. `ClassResult` is defined in `classifier.py` (Task 3) as `(label: str|None, confidence: float|None, note: str)`; in this task define it in `routing.py` as `@dataclass(frozen=True) class ClassResult: label: str | None; confidence: float | None; note: str` and Task 3 imports it.

`route` algorithm:
1. lever ≠ rules → `Decision(lever, "lever", [{"rule": "Lever", "outcome": "sending everything to <track>", "decided": True}])`.
2. For each rule in order: disabled → outcome `"switched off"`. After a decision, remaining rules get `"not reached"`.
   - dsl: first matching line decides; reason `"rule:<name>"` or `"rule:<name>:<n>"` (1-based) if the rule has >1 line; outcome `"line n matched → <track>"` or `"no match"`.
   - classifier: if `f.tier == "opus"` → outcome `"skipped: main session (opus)"`, no call. Else `r = classify(f, cfg.classifier)` (once per `route` call, memoised and shared with the `label` field). Decides when `r.label` maps to a track and `r.confidence >= threshold`; reason `"about:<label>"`, outcome `"<label>, <pct>% sure → <track>"`. Otherwise outcome is `r.note` (e.g. `"timed out after 1.5 s"`, `"error: …"`) or `"<label>, <pct>% sure, below <thr>%"`.
   - `label` field for dsl rules: `"none"` if tier is opus or the classifier rule is disabled; else the memoised result's label (if confidence ≥ threshold) or `"none"`.
3. Nothing decided → `Decision(cfg.otherwise, "default", …)` with a final item `{"rule": "Otherwise", "outcome": "→ <track>", "decided": True}`.

### Task 3: Prompt classifier

**Files:**
- Create: `classifier.py`
- Test: `tests/test_classifier.py`

**Interfaces:**
- Consumes: `routing.Features`, `routing.ClassifierSettings`, `routing.ClassResult`.
- Produces: `class Classifier: __init__(self, litellm_url: str, litellm_key: str, cache_size: int = 512)`; `__call__(self, f: Features, s: ClassifierSettings) -> ClassResult` (usable directly as `route`'s `classify`).

Behaviour:
- Cache key `(f.turn_key, settings fingerprint)` where the fingerprint covers model + labels (changing labels invalidates). LRU via `OrderedDict`, `cache_size` entries. Cached results returned without a call.
- In-flight dedupe: a dict key → `threading.Event`; a second caller for the same key waits on the same event (within its own time limit) instead of calling again.
- Call runs in a daemon thread; the caller waits `s.timeout_s`. On timeout returns `ClassResult(None, None, "timed out after %g s" % timeout)`; the thread still stores its result in the cache when it finishes.
- Request: `POST {litellm_url}/v1/chat/completions`, header `Authorization: Bearer <key>`, body `{"model": s.model, "temperature": 0, "max_tokens": 200, "messages": [{"role": "system", "content": <instruction>}, {"role": "user", "content": f.text[:4000]}]}`. Instruction lists each label as `- <name>: <description>` and asks for only JSON `{"label": "<one of the names>", "confidence": <0..1>}`.
- Parse: take `choices[0].message.content`, find the first `{...}` (regex `\{.*?\}` with DOTALL), `json.loads`. Unknown label, missing/non-numeric confidence, or confidence outside 0–1 → `ClassResult(None, None, "error: unusable answer")`. HTTP/network error → `ClassResult(None, None, "error: <short reason>")`. Errors and unusable answers are cached too (one call per turn, even when failing).
- Never logs the text.

### Task 4: Config file and stats store

**Files:**
- Create: `store.py`
- Test: `tests/test_store.py`

**Interfaces:**
- Consumes: `routing.config_from_json`, `config_to_json`, `DEFAULT_CONFIG`.
- Produces:
  - `load_console_config(path: str) -> tuple[RoutingConfig, str | None]` — missing file → `(DEFAULT_CONFIG, None)`; unreadable/invalid → rename to `path + ".bad"`, log to stderr, return `(DEFAULT_CONFIG, "Your saved settings couldn't be read (<reason>). They were moved to console.json.bad and defaults are in use.")`.
  - `save_console_config(path: str, cfg: RoutingConfig) -> None` — write temp file in same dir, `os.chmod 0o600`, `fsync`, `os.replace`. Creates parent dir (0o700) if missing.
  - `class Store: __init__(self, path: str, queue_max: int = 10_000)` — creates the db (0600) and schema, starts one daemon writer thread. `next_id() -> int` (thread-safe counter seeded from `max(id)` of `requests`).
  - Writes (non-blocking, `queue.put_nowait`; on `queue.Full` increment `self.dropped` and return): `record_request(row: dict)`, `record_pair(row: dict)`, `record_turn(row: dict)` (insert-or-ignore), `close()` (flush + stop; for tests).
  - Reads (each opens its own short-lived connection): `departures(since_id: int | None = None, before_id: int | None = None, limit: int = 200) -> list[dict]` newest first; `request(id: int) -> dict | None`; `stats(now: float) -> dict` with keys `anthropic_pct, local_pct, last_hour_total, per_minute, errors_last_hour, doubled_turns_today, judged_today, tally: {"local": n, "anthropic": n, "same": n}`; `turns(unjudged_first: bool = True, limit: int = 100) -> list[dict]`; `turn(turn_id: str) -> dict | None` with `steps` (pairs ordered by step); `set_verdict(turn_id: str, verdict: str) -> bool` (`"local"|"anthropic"|"same"`; synchronous); `forget_pairs() -> None` (deletes all pairs and turns; synchronous).
  - Pruning: on startup and then hourly in the writer thread, delete `requests` older than 30 days.

Schema:
```sql
CREATE TABLE IF NOT EXISTS requests(id INTEGER PRIMARY KEY, ts REAL, track TEXT, reason TEXT,
  explanation TEXT, model_in TEXT, model_out TEXT, status INTEGER, ttfb_ms INTEGER, ms INTEGER,
  stream INTEGER, preview TEXT, turn_id TEXT);
CREATE INDEX IF NOT EXISTS requests_ts ON requests(ts);
CREATE TABLE IF NOT EXISTS turns(id TEXT PRIMARY KEY, ts REAL, preview TEXT, verdict TEXT);
CREATE TABLE IF NOT EXISTS pairs(id INTEGER PRIMARY KEY AUTOINCREMENT, turn_id TEXT, request_id INTEGER,
  step INTEGER, served_track TEXT, shadow_track TEXT, served TEXT, shadow TEXT);
```
`served`/`shadow` are JSON: `{"status": int|null, "skipped": "busy"|null, "error": str|null, "ttfb_ms": int|null, "ms": int|null, "output_tokens": int|null, "text": str, "tools": [{"name": str, "input": str}]}`. `preview` = first 120 chars of newest human text. `explanation` = JSON list from `Decision.explanation`. A request is an error when `status >= 500` or `status == 0`.

### Task 6: Doubling

**Files:**
- Create: `doubling.py`
- Modify: `signaller.py`
- Test: `tests/test_doubling.py`

**Interfaces:**
- Consumes: `open_upstream`, `local_headers`, `local_model`, `routing.Features`/`Doubling`, `Store.record_pair`/`record_turn`.
- Produces:
  - `class AnswerCapture: __init__(self, content_type: str)`; `feed(chunk: bytes) -> None`; `result() -> dict` with `text: str`, `tools: list[{"name", "input"}]` (input = JSON string, truncated to 2 000 chars), `output_tokens: int | None`. For `text/event-stream`: parse SSE events across chunk boundaries — `content_block_start` (tool_use → new tool with name), `content_block_delta` (`text_delta` → text; `input_json_delta` → current tool input), `message_delta` (`usage.output_tokens`). For JSON: parse at `result()` from `content[]` and `usage.output_tokens`. Never raises on garbage (returns what it has). Text capped at 50 000 chars.
  - `class Doubler: __init__(self, store: Store, open_upstream: Callable, rng: random.Random | None = None)`; `turn_for(f: Features, served_track: str, d: Doubling) -> str | None` — returns a turn id if this request should be doubled, else None; `start_shadow(turn_id, request_id, f, served_track, method, path, headers, body, cfg) -> None` (spawns a daemon thread; returns immediately); `pending_served(turn_id, request_id, step, served_track) -> PairHandle` with `finish(served: dict)`; `active() -> dict` (in-flight counts, for tests).
  - Selection (`turn_for`): candidate turn = (`d.tag` empty or `d.tag.lower()` in `f.tags`). Direction check uses the **served** track: served local needs `d.when_local`, served anthropic needs `d.when_anthropic`. The turn decision is made once per `f.turn_key` and cached with its turn id; entries expire after 30 minutes without a request (a later identical message is a new turn). Chosen with probability `d.rate` (`rng.random() < rate`; rate 1 always, 0 never). Direction is re-checked per request (a turn whose requests switch tracks only doubles the allowed ones). On first choice `store.record_turn({"id", "ts", "preview"})`. Step numbers count per turn from 1.
  - Caps: `threading.BoundedSemaphore` — 1 for shadows **to local**, 2 for shadows **to anthropic**, acquired non-blocking. Not acquired → record the pair with shadow `{"skipped": "busy", ...}` and no upstream call.
  - Shadow request: other track. To local: body with `model` = `local_model(...)` and `stream` false; headers `local_headers(...)`. To anthropic: original body with `stream` false; original headers minus HOP (credentials only in memory). Uses `open_upstream`, reads the full JSON with `AnswerCapture("application/json")`, records status/ttfb/ms/error.
  - Pair row is written once both sides are known (`PairHandle` joins the served capture and the shadow result; whichever finishes second writes the pair).

Proxy changes in `signaller.py`: for `POST /v1/messages` with features: `turn_id = app.doubler.turn_for(f, d.track, app.routing.doubling)`; if set, `start_shadow(...)` **before** opening the served upstream, and tee the served response chunks into an `AnswerCapture` (feed after `wfile.write`+`flush`, so bytes are never held). After the served response ends, finish the pair with served status/ttfb/ms. Record `turn_id` on the request row. Log `shadow=<track>` or `shadow=busy` or `shadow=-`. Only `/v1/messages` is doubled.
